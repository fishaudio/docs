These are the tools the [Fish Audio MCP server](/overview/mcp) exposes. Naming one in a prompt helps when you want to steer a step, for example "List my own voices with `search_voices`."

The agent gets each tool's arguments and full description from the server when your client connects; the tables show the first sentence of each description. Costs are in [Credits](/overview/mcp#credits), and plan requirements in [Good to know](/overview/mcp#good-to-know).

| Tool                 | What it does                                                                                                                                                                                                                                | Read-only | Charges credits |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------- | --------------- |
| `search_voices`      | Search public voices (TTS models) on Fish Audio, or list your own with self=true (includes private and team-shared voices).                                                                                                                 | Yes       |                 |
| `get_voice`          | Get details of one Fish Audio voice by its id: description, languages, tags, popularity stats, a sample audio URL and a default demo text.                                                                                                  | Yes       |                 |
| `create_voice_clone` | Clone a voice from sample audio and get a voice usable with `text_to_speech`.                                                                                                                                                               |           |                 |
| `verify_voice_clone` | Complete speaker verification for a voice clone that returned verification_required: the actual speaker records themselves reading the exact prompt sentence, the recording is uploaded (use `get_upload_url`), and its URL is passed here. |           |                 |

## Speech and transcription

Long text may come back as several clips. How much text one call can take depends on your plan, and `get_credit_balance` shows the limit. A long text can take minutes: after about 45 seconds `text_to_speech` returns a task id, and `get_speech` returns the audio when it is ready. If a call's response is lost, `list_speech_history` finds it, so the agent does not pay for it twice.

| Tool                  | What it does                                                                                                                                      | Read-only | Charges credits |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | --------- | --------------- |
| `text_to_speech`      | Generate speech audio from text with one Fish Audio voice, or a multi-speaker dialogue with several, and return a permanent audio URL.            |           | Yes             |
| `get_speech`          | Check a `text_to_speech` generation by its task_id.                                                                                               | Yes       |                 |
| `list_speech_history` | List your recent speech generations in this workspace, newest first, with each one's status, the start of its text and, once done, its audio_url. | Yes       |                 |
| `speech_to_text`      | Transcribe speech audio to text.                                                                                                                  |           | Yes             |

## File uploads

Both tools return an upload link, and the agent then uploads the file to it. In clients that cannot upload files themselves, such as claude.ai, the agent gives you a link to upload the file from your browser instead. Anyone with the link can upload to it until it expires, so don't share it.

| Tool                  | What it does                                                                                                                                                                                                                                        | Read-only | Charges credits |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------- | --------------- |
| `get_upload_url`      | Get a temporary upload slot for a local audio file, or a script file (.docx / .pdf / .txt) for `studio_import_script`: HTTP PUT the raw file bytes to upload_url (within 1 hour), then pass file_url to `speech_to_text` or `studio_import_script`. |           |                 |
| `create_media_upload` | Create a one-hour workspace-scoped upload slot for an image, video or audio input, only for a file that is not in Fish yet.                                                                                                                         |           |                 |

## Story Studio

A project holds chapters, and chapters hold blocks (a paragraph or heading), each with its own voice. These tools edit the same projects as the [Story Studio editor](https://fish.audio/app/story-studio), and edits show up in an open editor. Importing and editing are free; audio [costs credits](/overview/mcp#credits), and the agent quotes it first.

A block needs new audio when it has none or its text, voice, or settings changed. If a block is changed back to an earlier version, `studio_generate` reuses that audio for free. No tool deletes projects or chapters; delete them in the editor.

A [voice acting](https://fish.audio/app/voice-acting) project is made of scenes, lines, and roles. `studio_import_script` reads a script into a draft for you to review, and `studio_create_project` then creates the project from it. `studio_perform` and `studio_retake` record lines with Drama 3, quoting the credits first. `studio_share` creates a public link where anyone who has it can listen to an export and comment line by line.

| Tool                     | What it does                                                                                                                                                                                                                                                                                                   | Read-only | Charges credits |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------- | --------------- |
| `studio_help`            | The operating manual for Story Studio (multi-speaker audio projects).                                                                                                                                                                                                                                          | Yes       |                 |
| `studio_list_projects`   | List the user's Story Studio projects (name, kind, chapter count, importing flag), newest first.                                                                                                                                                                                                               | Yes       |                 |
| `studio_project`         | Project overview: chapter outline (anchors, titles, block/dirty counts, durations), speaker roster, and live import/export job state.                                                                                                                                                                          | Yes       |                 |
| `studio_create_project`  | Create a studio project from structured chapters (max 200 blocks — use `studio_import_document` for whole books).                                                                                                                                                                                              |           |                 |
| `studio_import_document` | Import a document or long text (novel, script, article — up to 1.5M chars) into a new studio project.                                                                                                                                                                                                          |           |                 |
| `studio_import_script`   | Parse a voice-acting script (.docx / .pdf / .txt / .md uploaded via `get_upload_url` — pass its storage_key or file_url — or pasted text) into scenes, lines and roles with suggested voices for the user to review; `studio_create_project`(kind="voice-acting", import_job_id=...) then creates the project. |           |                 |
| `studio_update_project`  | Project-wide settings: rename, default voice/backend for new blocks, audio settings defaults, scene_preset (off\|studio adds room ambience), chapter_order (list of chapter anchors) to reorder chapters.                                                                                                      |           |                 |
| `studio_read_blocks`     | Read blocks: pass chapter (anchor) for a whole chapter (paginated) or blocks (list of anchors) for specific ones.                                                                                                                                                                                              | Yes       |                 |

| `studio_generate`        | Synthesize audio for blocks: pass blocks (anchors) or chapter, or neither for the whole project.                                                                                                                                                                                                               |           | Yes             |

## Asset library

Your workspace's [Asset Library](https://fish.audio/app/assets) holds saved images, audio, and video in folders, plus avatars, which pair a portrait image with an optional default voice. These tools never delete anything; delete files in the web app.

| Tool                      | What it does                                                                                | Read-only | Charges credits |
| ------------------------- | ------------------------------------------------------------------------------------------- | --------- | --------------- |
| `list_assets`             | List direct assets; search without collection_id searches the workspace.                    | Yes       |                 |
| `get_asset`               | Read asset original object_key and temporary download URL.                                  | Yes       |                 |
| `save_asset`              | Save a completed upload or successful task result.                                          |           |                 |
| `update_asset`            | Rename/move an asset.                                                                       |           |                 |
| `list_asset_collections`  | List direct child folders/avatars/styles; all=true returns a flat tree.                     | Yes       |                 |
| `get_asset_collection`    | Read folder position or avatar portrait/default voice; list children and images separately. | Yes       |                 |
| `create_asset_folder`     | Create an ordinary nested folder.                                                           |           |                 |
| `create_avatar`           | Create an avatar from one prepared image source, optionally bind an existing voice.         |           |                 |
| `update_asset_collection` | Rename/move ordinary folders or edit avatar name/default voice/portrait.                    |           |                 |
