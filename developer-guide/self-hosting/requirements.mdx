These are the baselines Fish Audio deploys against. Throughput and time-to-first-audio
depend on your GPU, text length, and concurrency, so confirm sizing with your account
team and measure on your own hardware before you commit to a capacity plan.

## Hardware

| Requirement   | Detail                                                                                                                                                                                                                          |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Hosts         | Linux x86-64 on every machine, CPU-only Kubernetes nodes included.                                                                                                                                                              |
| GPU type      | NVIDIA H100, H200, or B300. Contact Fish Audio before standardizing on any other GPU.                                                                                                                                           |
| GPU count     | **One**: Single-GPU mode, All-in-One only, with lower throughput.<br />**Two**: recommended. One for the inference worker, one for the vocoder.<br />**Three**: adds timestamp alignment, where available.<br />**More**: scales throughput on Kubernetes; size it with your account team. |
| GPU memory    | The worker pre-allocates most of its card for the KV cache, so a near-full card is expected, not a fault.                                                                                                                       |
| MIG           | Disable MIG unless the configuration has been validated with Fish Audio.                                                                                                                                                        |
| NVIDIA driver | Must support CUDA 13.x and your card's compute capability.                                                                                                                                                                      |

## Network

| Traffic    | Requirement                                                                                                                                                                  |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Install    | Access to the Fish Audio registry to pull the images and, on Helm, the chart. For a site with no outbound access, see [Air-gapped deployments](/developer-guide/self-hosting/air-gapped). |
| Billing    | With online billing, every request is authorized over HTTPS against the Fish Audio billing endpoint; ask your account team for the hostname to allowlist. Offline billing needs no outbound access. |
| Voice sync | Optional. When turned on, the deployment downloads voices from Fish Audio over HTTPS.                                                                                       |
| Inbound    | Your own ingress, load balancer, or private endpoint, with DNS and TLS in place before production traffic.                                                                  |

## Helm (Kubernetes)

| Requirement     | Detail                                                                                                                                                       |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Control plane   | 3 CPU-only nodes, roughly 4 vCPU and 16 GB RAM each, for the control plane or, on managed Kubernetes, the system node group.                                 |
| CPU workloads   | Roughly 28 vCPU and 125 GiB of memory requests for the non-GPU services. Provide a CPU node group, or leave GPU nodes schedulable for them.                  |
| Shared storage  | At least 1 TB of EFS, NFS, or equivalent, mounted at the same path on every node (`/mnt/shared` by default). The chart mounts it with hostPath and creates no PersistentVolumeClaims. |
| Node-local disk | Redis keeps its data on node-local ephemeral storage. Leave room for it on the nodes that host it, plus headroom for rewrites.                                 |
| Kubernetes      | A currently supported minor version and a maintained Helm release.                                                                                          |
| GPU runtime     | NVIDIA GPU Operator, or the provider's driver and device plugin, with GPU nodes exposing `nvidia.com/gpu`.                                                  |
| Pod Security    | The namespace must permit `hostPath` volumes for every service on shared storage, and `hostPID` and `hostIPC` for the inference workers.                     |

<Warning>
  The shared mount is created with `DirectoryOrCreate`. A node that is missing it
  silently gets a local directory instead, and the deployment looks healthy while data
  splits across nodes. Verify the mount, and that it is writable, on **every** node
  before installing.
</Warning>

## All-in-One (Docker)

| Requirement | Detail                                                                                                                                         |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| Docker      | Docker Engine 24 or newer, with the NVIDIA Container Toolkit installed and its `nvidia` runtime registered.                                     |
| CPU and RAM | 32 vCPU and 128 GiB minimum; 48 to 64 vCPU and 192 GiB recommended.                                                                            |
| Disk        | 100 GB free to pull the image, or 120 GB to load it from a file. Plus a persistent volume for caches, voices, and the usage ledger; local disk is enough. |
