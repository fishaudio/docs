<Update label="JavaScript SDK 0.2.0" description="November 25, 2026" tags={["Fish Audio"]}>
  ## JavaScript SDK 0.2.0

  `fish-audio` 0.2.0 on npm adds realtime speech to text with `transcribe-stream-1` (`speechToText.convertRealtime()`, Node.js only), a `model` option for `speechToText.convert()`, the `s2.1-pro`, `s2.1-pro-free` and `drama-3` models in the `Backends` type, multi-speaker text to speech, and more TTS request fields. `require("fish-audio")` works again.

  Upgrade notes: the default TTS model is now `s2.1-pro` (0.1.0 sent the deprecated `s1`), `opus_bitrate` is in bits per second, reference audio must be a `File`, and Node.js 20 or later is required.

  [JavaScript SDK reference](/api-reference/sdk/javascript/api-reference#upgrade-notes) | [Release notes](https://github.com/fishaudio/fish-audio-typescript/releases/tag/v0.2.0)
</Update>

<Update label="Drama 3 audio infill" description="November 18, 2026" tags={["Fish Audio"]}>
  ## Drama 3 audio infill

  Edit part of an existing recording without re-recording it using `POST /v1/audio/infill` with `model: drama-3`. Send the original audio, the full revised `transcript`, and the span to replace in seconds (`prefix_seconds`, `suffix_seconds`) or frames (`prefix_frames`, `suffix_frames`), and Drama 3 regenerates only that span in the speaker's voice taken from the surrounding audio.

  You can also join or continue separate recordings with `prefix_audio` and optional `suffix_audio`. Requests accept `multipart/form-data` or `application/msgpack`, and sending `Accept: text/event-stream` streams the output along with the regenerated span's timestamps.

  [Audio Infill](/features/text-to-speech/audio-infill) | [Audio Infill API](/api-reference/endpoint/openapi-v1/audio-infill)
</Update>

<Update label="Exposed API key revocation" description="November 13, 2026" tags={["Fish Audio"]}>
  ## Exposed API key revocation

  Revoke exposed Fish Audio API keys without signing in using `POST /apikey/revoke`. Built for secret scanners, partners, security researchers, and key owners, each request accepts up to 1,000 keys in `credentials`, permanently deletes any matching keys, notifies the key creator (and team owner for team keys) by email, and always returns an empty `202` response.

  [Revoke Exposed API Keys](/api-reference/endpoint/apikey/revoke-api-keys)
</Update>

<Update label="Live 3 full-duplex model" description="November 10, 2026" tags={["Fish Audio"]}>
  ## Live 3 full-duplex model

  Live 3 is our full-duplex speech model for Voice Agents (`voice.engine: "live3"`). Instead of waiting for a caller to finish before generating speech, a single model listens while it speaks and decides when to backchannel, wait, respond, or stop on real interruptions and mid-turn corrections.

  New agents start on Live 3 by default for English sessions. Choose from eight built-in Live 3 voices (`clara`, `nora`, `harper`, `patricia`, `owen`, `marco`, `milo`, `jonah`) or any Voice Library voice, and tune turn-taking with situation prompts (`P2` phone support, `DT` drive-thru, or `AIR` airline). Sessions in other languages automatically use the agent's cascade text-to-speech model.

  [Live 3 (full duplex)](/agents/build/voice-language#live-3-full-duplex) | [Cascade vs. full duplex](/agents/concepts#cascade-vs-full-duplex)
</Update>

<Update label="transcribe-1 retirement" description="October 29, 2026" tags={["Fish Audio"]}>
  ## transcribe-1 retirement

  `transcribe-1` is deprecated and will be retired on December 31, 2026, together with S1. After that date, the requests it serves are served by `transcribe-1-pro` and billed as `transcribe-1-pro`, at the same price. This includes requests with no `model` header, or one that does not match exactly, and requests through the OpenAI-, Groq-, OpenRouter-, and ElevenLabs-compatible endpoints.

  To migrate, send the `model: transcribe-1-pro` header on `POST /v1/asr`. For plain transcripts without speaker markers or event cues, also send `diarize=false` and `tag_audio_events=false`.

  [Migrate from transcribe-1](/developer-guide/models-pricing/migrate-from-transcribe-1) | [Model deprecations](/developer-guide/models-pricing/deprecations)
</Update>

<Update label="Realtime Speech to Text (transcribe-stream-1)" description="October 20, 2026" tags={["Fish Audio"]}>
  ## Realtime Speech to Text (`transcribe-stream-1`)

  Stream live 16-bit PCM audio over `wss://api.fish.audio/v1/asr/realtime` for turn-by-turn transcription powered by `transcribe-stream-1`. Beyond live `draft` transcripts with `settled_text`, Smart Turn Detection (`auto`, `vad`, and `manual` modes) handles eager end-of-turn signals, backchannel detection, and background awareness, alongside conversation context (`context.terms`, `context_add`, `context.history`), speaker diarization, and optional sound event tags (`results.tag_audio_events`).

  Sessions run up to 60 minutes. `transcribe-stream-1` is also available as a speech recognition model in Voice Agents (`fish_audio:transcribe-stream-1`).

  [Realtime Speech to Text](/features/speech-to-text/realtime) | [WebSocket reference](/api-reference/endpoint/websocket/asr-realtime)
</Update>

<Update label="TTS language field" description="October 16, 2026" tags={["Fish Audio"]}>
  ## TTS language field

  Text-to-speech requests accept an optional `language` field, a BCP-47 tag of the text such as `en`, `es-MX`, or `zh-TW`. It selects the rules used to spell out numbers, dates, units, and symbols before synthesis, and the language used for word timestamps. It does not change the voice, accent, or audio quality. Omit it to keep detecting the language per text chunk.

  Available on `POST /v1/tts`, the with-timestamps routes, and the WebSocket start event. The official SDKs don't expose it yet.

  [Language](/features/text-to-speech#language) | [Supported normalization languages](/features/text-to-speech#supported-normalization-languages)
</Update>

<Update label="Fish Audio S2" description="March 2026" tags={["Fish Audio"]}>
  ## Fish Audio S2

  Next-generation text-to-speech model with inline emotion cues, multi-speaker dialogue support, and 80+ languages.

  S2 introduces `[bracket]` syntax for natural language control over emotion and paralinguistic cues (e.g., `[whisper]`, `[laugh]`, `[emphasis]`). Tags are treated as standard text rather than dedicated control tokens, so you are not limited to a fixed set of expressions. Built on the Qwen3-4B backbone and fully open-source.

  Use model ID `s2-pro` in the API. At launch, S1 remained supported for existing integrations; it is now deprecated and will be retired on December 31, 2026 (see [Migrate from S1](/developer-guide/models-pricing/migrate-from-s1)).

  [GitHub](https://github.com/fishaudio/fish-speech) | [HuggingFace](https://huggingface.co/fishaudio)
</Update>
