Use this endpoint when you want Fish to provide turn detection. Read the [Duplex API guide](/features/duplex-api) for the architecture, starter application, and conversation flow.

Every message is a binary WebSocket frame containing a MessagePack map. Audio
payloads use MessagePack binary data, not base64 strings.
