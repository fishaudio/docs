A new dictionary has no rules and no version. [Publish a version](/api-reference/endpoint/pronunciation-dictionary/create-version) to add rules, then reference the dictionary ID and version ID in your [TTS requests](/developer-guide/core-features/fine-grained-control/pronunciation-dictionaries#use-a-published-dictionary).
